## About

**The Imp Games** is a custom host-only Among Us mod focused on fun roles, mystery, and chaotic private lobbies.

This mod is based on **Endless Host Roles**.

Original project credit:  
https://github.com/Gurge44/EndlessHostRoles

---

## Features

- Host-only gameplay
- Custom Crewmate roles
- Custom Impostor roles
- Experimental role ideas
- Private lobby support
- Easy settings customization

A Crewmate role that unlocks its power after finishing all tasks.

After completing tasks, the Imp Hunter can sense danger and reveal two red names:
